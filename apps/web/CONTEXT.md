# Web

瀏覽器端的介面：對話、側欄、卡片與它們共用的外觀。這一份只收「元件」相關、容易混用的詞；怎麼做見 [`COMPONENTS.md`](./COMPONENTS.md)，值見 [`.docs/web-ui-spec.md`](../../.docs/web-ui-spec.md)。

## Language

**registry 元件**:
從 shadcn registry 裝進來的元件，放在 `ui/`。裝進來就是我們的原始碼，但只在 registry 原文上做登記過的修改。
_Avoid_: 原件、基礎元件、shadcn 元件（自己寫的元件也常用 shadcn 的樣子，分不出來）

**積木**:
從兩處以上**同一份配方**抽出來的共用元件，只含共通的部分，差異由用的地方補。今天有：表面、可展開列、展開箭頭。
_Avoid_: 元件（太泛）、共用元件、primitive

**功能元件**:
只為一個功能存在的元件，放在按功能分的資料夾（工具、待辦、側欄……）或元件根目錄。由 registry 元件與積木組成。
_Avoid_: 業務元件、頁面元件

**AI 專屬元件**:
只有 agent 介面才有的那一類功能元件：核准、工具呼叫、思考過程、逐字串流、任務列、輸入列、提問。參考對象是 beautiful-ui。
_Avoid_: agent 元件、聊天元件（輸入框、泡泡這種一般聊天介面也有的不算）

**參考對象**:
外觀與互動模仿的外部專案，**只看不裝**：一般元件看 Libraries.dev，AI 專屬元件看 beautiful-ui。用它們的結構與手感，換成我們的值與積木重寫。
_Avoid_: 依賴、上游、設計系統（我們的設計系統是自己的那一套）

**配方**:
一組一起出現、合起來代表一種外觀的樣式（例如卡片的底色＋陰影＋圓角）。同一份配方手寫第二次，就該抽成積木。
_Avoid_: 樣式組合、class 串
