# 會話日誌格式升到 53

## 變更

v0.6.0 寫的會話日誌是格式 52，新版是 53（[#2367](https://github.com/DemianLi/nexus-agent/issues/2367)）。53 多了兩樣：從嵌入的對話框開的
對話，header 記著 `profile: 'embed'`；嵌入的頁面附在一句話上的畫面情境，記在那一句的 `context`。每一版改了什麼，紀錄在
[`packages/nexus-core/src/session-store.ts`](../../../../packages/nexus-core/src/session-store.ts) 的檔頭。

- **新版讀舊檔不用轉換**：52 以前的對話照讀，等於獨立頁面開的、沒附情境。
- **續接時遷移**：新版接著寫一條 52 的對話時，先把 `<id>/session.v52.jsonl` 的內容原樣複製成同一個目錄裡的 `session.v53.jsonl`，
  舊的那份留著不動；只是打開來看（列表、搜尋、看內容）不遷。遷移當下那份對話要兩倍的磁碟，遷完之後舊的那份也一直佔著。
- **單向**：同一個目錄裡有好幾個世代時，v0.6.0 一律挑最高的那個，比它新就拒讀，不退回去讀 `session.v52.jsonl`。所以新版續接過的
  對話與新版新開的對話，換回 v0.6.0 之後都讀不了；新版沒續接過的照常讀得到。

受影響的：之後可能要退回 v0.6.0 的主機。

## 遷移

1. 往前升不用做任何事。磁碟要留得下最大那幾份對話各多一份。
2. 可能要退回的話，升級前照 [`docs/operations.md`〈升級與回滾〉](../../../operations.md#升級與回滾) 備份整個 home
   （給了 `--session-log` 的話連那個目錄）；退回時還原備份，不要只把程式換回去。
3. 確認：新版起來之後開一條升級前的舊對話、送一句話，內容都在；側欄沒有「讀不了 N 條」；那條對話的目錄裡多了這一版的世代檔（跟 54 一起發的話是 `session.v54.jsonl`），
   `session.v52.jsonl` 還在。
