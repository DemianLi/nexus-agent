# 會話日誌格式升版

## 變更

v0.5.19 寫的會話日誌是格式 14，新版是 49。每一版改了什麼、讀舊檔怎樣，紀錄在
[`packages/nexus-core/src/session-store.ts`](../../../../packages/nexus-core/src/session-store.ts) 的檔頭（格式紀錄的唯一來源）。

- **新版讀舊檔不用轉換**：只拒讀比自己新的版本，沒有最低版本；檔名佈局（`<id>.header.json`、`<id>.jsonl`、`<id>.lock`）沒變。
- **單向**：新版接著寫一條舊對話時，header 的版本蓋成新版的號；新開的對話一開始就是新版的號。之後換回 v0.5.19，
  這些對話會被拒讀（「…的格式版本是 49，這一版只讀得懂到 14。檔案沒有壞，是比這一版新。」）。新版沒碰過的照常讀得到。

受影響的：之後可能要退回 v0.5.19 的主機。

## 遷移

1. 往前升不用做任何事。
2. 可能要退回的話，升級前照 [`docs/operations.md`〈升級與回滾〉](../../../operations.md#升級與回滾) 備份整個 home
   （給了 `--session-log` 的話連那個目錄）；退回時還原備份，不要只把程式換回去。
3. 確認：新版起來之後開一條升級前的舊對話，內容都在；側欄沒有「讀不了 N 條」。
