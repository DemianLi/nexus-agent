# 會話日誌格式升版

## 變更

v0.5.19 寫的會話日誌是格式 14，新版是 52。每一版改了什麼、讀舊檔怎樣，紀錄在
[`packages/nexus-core/src/session-store.ts`](../../../../packages/nexus-core/src/session-store.ts) 的檔頭（格式紀錄的唯一來源）。

- **檔名佈局換了**（格式 52，[#1594](https://github.com/DemianLi/nexus-agent/issues/1594)）：v0.5.19 是三個檔並排（`<id>.header.json`、
  `<id>.jsonl`、`<id>.lock`）；新版一份會話一個目錄，`<id>/session.v52.jsonl`（第一行是 header 行）加 `<id>/session.lock`，
  舊路徑的 `<id>.header.json` 換成一份墓碑。目錄名與舊檔名的編法不同（`/` 編成 `~002F`，不是 `%2f`），直接照檔名找日誌的腳本要改，
  見 [`docs/operations.md`](../../../operations.md) 的會話日誌一節。
- **新版讀舊檔不用轉換**：舊兩檔照讀，只拒讀比自己新的版本，沒有最低版本。
- **續接時遷移**：新版接著寫一條舊對話時，先把舊日誌已接受的那一段原樣複製成新的世代檔，舊日誌留著不動，舊 header 換成墓碑；
  只是打開來看（列表、搜尋、看內容）不遷。遷移當下那份對話要兩倍的磁碟，遷完之後舊日誌也一直佔著。
- **單向**：遷過的對話與新版新開的對話，在舊路徑都是格式 52 的墓碑。之後換回 v0.5.19，這些對話會被當成比它新而拒讀；
  新版沒續接過的照常讀得到。

受影響的：之後可能要退回 v0.5.19 的主機；照檔名讀會話日誌的腳本。

## 遷移

1. 往前升不用做任何事。磁碟要留得下最大那幾份對話各多一份。
2. 可能要退回的話，升級前照 [`docs/operations.md`〈升級與回滾〉](../../../operations.md#升級與回滾) 備份整個 home
   （給了 `--session-log` 的話連那個目錄）；退回時還原備份，不要只把程式換回去。
3. 照檔名讀日誌的腳本：把 `<目錄>/<id>.jsonl` 換成 `<目錄>/<id>/session.v*.jsonl`，第一行是 header 行，事件從第二行起。
4. 確認：新版起來之後開一條升級前的舊對話、送一句話，內容都在；側欄沒有「讀不了 N 條」；那條對話在會話根底下多了一個同名目錄，
   裡面有 `session.v52.jsonl`。
