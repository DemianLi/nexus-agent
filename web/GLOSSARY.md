# Web

瀏覽器端的介面：對話、側欄、卡片與它們共用的外觀。這一份收「元件」相關與側欄會話管理裡容易混用的詞；怎麼做見 [`COMPONENTS.md`](./COMPONENTS.md)，值見 [`.docs/web-ui-spec.md`](../.docs/web-ui-spec.md)。

## Language

**基礎元件**:
放在 `ui/` 的元件：原檔是 vendor 的 solid-glass 元件（`src/vendor/solid-glass/components/ui/`），`ui/` 是轉出它的 nexus 層。vendor 檔不手改，修改寫在 nexus 層、覆寫檔或 patch，逐條登記在 [vendor README](src/vendor/solid-glass/README.md) 的「本地修改」。
_Avoid_: 原件、registry 元件、shadcn 元件（自己寫的元件也常用 shadcn 的樣子，分不出來）

**積木**:
從兩處以上**同一份配方**抽出來的共用元件，只含共通的部分，差異由用的地方補。在設計系統的分層裡叫「共用元件」（規格 §13.5、[`COMPONENTS.md`](./COMPONENTS.md)「共用元件一覽」底下「共用元件」那張表），指的是同一批東西。今天有：表面、可展開列、展開箭頭、對話泡泡、程式碼小框、複製鈕（清單以 [`COMPONENTS.md`](./COMPONENTS.md)「什麼時候抽共用元件」為準）。
_Avoid_: 元件（太泛）、primitive

**功能元件**:
只為一個功能存在的元件，放在那個功能的切片裡。由基礎元件與積木組成。
_Avoid_: 業務元件、頁面元件

**AI 專屬元件**:
只有 agent 介面才有的那一類功能元件：核准、工具呼叫、思考過程、逐字串流、任務列、輸入列、提問。參考對象是 beautiful-ui。
_Avoid_: agent 元件、聊天元件（輸入框、泡泡這種一般聊天介面也有的不算）

**參考對象**:
**只看不裝**的外部專案：solid-glass 沒有定義的元件或互動，元件多樣性與交互模式看 Libraries.dev；AI 專屬元件看 beautiful-ui。用它們的結構與手感，換成我們的值與積木重寫。solid-glass 是 vendor 進來的，不算參考對象。
_Avoid_: 依賴、上游、設計系統（我們的設計系統是自己的那一套）

**切片**:
一個功能的資料夾（`src/features/<名字>/`）：那個功能的元件、hook、純邏輯與測試都在裡面。清單與規則見 [`ARCHITECTURE.md`](./ARCHITECTURE.md)。
_Avoid_: 模組、feature、功能資料夾

**公開入口**:
切片的 `index.ts`。切片外面的程式只能從這裡拿東西，裡面的檔怎麼分是切片自己的事。
_Avoid_: barrel、API、匯出檔

**共用層**:
兩個以上切片都要用的東西：`src/shared/`、`ui/` 的基礎元件、樣式與 vendor。它不認得任何切片。
_Avoid_: common、utils、基礎層

**組裝層**:
把切片接成畫面的地方（`src/app/`）。只有它可以同時認得好幾個切片。
_Avoid_: 頁面層、容器

**配方**:
一組一起出現、合起來代表一種外觀的樣式（例如卡片的底色＋陰影＋圓角）。同一份配方手寫第二次，就該抽成積木。
_Avoid_: 樣式組合、class 串

**封存**:
把一條會話收進側欄時間組之後的「已封存」區：檔案不動、隨時可以取消封存，但封存期間它不跑模型（送話也不會呼叫模型）。還在跑的要一併停掉（確認框的「停掉並封存」）才封存得了。
_Avoid_: 刪除、隱藏、歸檔

**刪除**:
把一條會話（連同它的子代理日誌）搬到 server 的已刪除存放區，從清單上拿掉；到期前可以從「最近刪除」復原，到期後只是不能復原，檔案仍留著。不是永久刪除。
_Avoid_: 封存、移除、永久刪除

**最近刪除**:
側欄最下面那一區：列出還沒到期的已刪除會話，每列寫還剩幾天，唯一的動作是「復原」。到期的不列。
_Avoid_: 垃圾桶、回收筒、已刪除
