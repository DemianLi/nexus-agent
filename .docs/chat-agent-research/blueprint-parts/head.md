# 對話 agent 的通用實作方案：從 206 篇論文歸納的分級決策

這是一份從本調研讀過的 206 篇論文歸納出來的通用實作方案：每個決策拆成「建議做法、起手預設值、換做法的條件、證據等級、怎麼驗收」，讓建造者可以直接動手，也知道這個建議靠不靠得住。它不是對照 nexus 或任何特定產品的缺口清單，各章（`chapters/`）與 README 仍維持純研究。證據範圍只有本調研讀過、有筆記的論文：沒讀的論文不當依據，讀過的論文沒有答案的地方，本文寫「文獻沒有答案」並列出要自己量什麼，不編建議。

> **套用到 nexus 時，AGENTS.md 規定的 DeepSeek Harness 做法優先；本文不能當作偏離它的依據。** 本文的等級只說明「文獻對這個做法有多少、多乾淨的證據」，不說明它符合哪個專案的規範。

**這份方案的形狀（先講結論，免得誤讀）**：證據最收斂的是「量測紀律」，也就是每個分數旁要並列什麼平凡基準、判分的資訊不能進迴圈、同名指標不能直接比，這些在八個節點反覆出現，所以放在元件選型之前（第 3 節）。元件選型（要用哪一種做法）的證據次之，而且多半只能寫成「先量過再上線」。端到端怎麼組起來（第 6 節）整節只能標推論：本調研讀過的論文沒有任何一篇驗過把這幾個節點接成一整條線。決策裡「建議做」型很少，多數是「避免」「量測規則」「待決」，這是文獻的實況，沒有為了湊平衡而調整。
