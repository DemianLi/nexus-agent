### 資料流

八個節點與六條邊（依 `data/topics.json`；T3 與 T8 不是任何一條邊的端點）：

```
離線迴圈（評估與改進）
  T6 使用者模擬器／真人回饋 ──E6 互動紀錄──→ T7 評估方法 ←──E5 修正紀錄── T5 自我修正
                                                   ↑ 分數怎麼定義與聚合：T8（判準與彙總）

一個回合（線上）
  使用者輸入 ──E1──→ T1 目標與意圖 ──→ T2 對話狀態 ──→ agent 行動
                                                          │
                          T3 觀測（工具回傳、監控）←──────┘
                                  │
                          T4 軌跡（記錄這一步）
                           │E3 偵測到異常 → T5 自我修正 ──E2 修正寫回──→ T2 對話狀態
                           │E4 沒有異常   → T6 繼續與使用者（模擬器）互動
```

E1（T6→T1）使用者輸入進入目標對齊；E2（T5→T2）修正結果寫回狀態；E3（T4→T5）偵測到異常觸發修正；E4（T4→T6）正常路徑繼續互動；E5（T5→T7）修正紀錄回流評估；E6（T6→T7）互動紀錄回流評估。這張圖只是地圖的文字版，不代表有論文驗過整條線（見第 6 節）。
